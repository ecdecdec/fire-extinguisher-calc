# Оформление приложения (направление версии 2.0)

Решение Д2 в docs/plan.md: вид по платформе. Приложение для работы (режим Operate в терминах скилла impeccable): привычные элементы платформы и удобство на обходе важнее выразительности. Нынешний вид (графитовая гамма, IBM Plex, моноширинные служебные строки по методике unslop) заказчик считает «ИИ-шным»: в версии 2.0 он заменяется.

## Общее

- Шрифт системы: Roboto на Android, Segoe UI на Windows, системный на сайте. IBM Plex убирается. PDF остаётся на Tinos.
- Моноширинный шрифт только в таблицах чисел.
- Цвет только со смыслом. Красный (#C1121C, как в знаках ГОСТ): нехватка, запрет, знаки пожарной безопасности. Зелёный: соответствует, эвакуация. Остальное в нейтральной гамме. Один красный на всё приложение.
- Контраст: текст не ниже 4,5:1, рамки полей и кнопок не ниже 3:1. Тема для солнца: ещё контрастнее.
- Отступы кратно 4 px.

## Телефон (Android, Material 3)

- Экраны вместо одной страницы: сверху строка с названием и стрелкой назад, главное действие внизу.
- Кнопки и строки списков от 48 px, основной текст 16 px, поле нажатия у флажков 44 px.
- Нижние панели вместо окон поверх страницы; сообщения внизу с действием «Отменить».
- Нет подсветки при наведении, выделения текста на кнопках, масштаба интерфейса двумя пальцами (масштаб только на схеме).
- Отступы под вырез и жестовую полосу; клавиатура не закрывает поле.

## Компьютер (Windows, Fluent)

- Окно в две-три колонки: объекты, схема или помещения, итог.
- Меню «Файл, Правка, Вид, Справка», сочетания клавиш, печать.
- Элементы 32 px, скругления 4 px, фон окна Mica на Windows 11.
