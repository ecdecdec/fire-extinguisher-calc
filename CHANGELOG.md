# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Номера версий по [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено
- Стенд проверки распознавания планов: синтетические планы и 59 общедоступных планов, метрики, базовый замер (`node tools/bench-vision.js`).
- Поиск углов листа плана на снимке, обрезка здания и выпрямление перспективы.
- Знаки ISO 7010 на схеме и в PDF вместо прежних значков; новый значок приложения (знак F04 «Огнетушитель»).
- Проверки в GitHub Actions: тесты, порог стенда распознавания, интерфейс в браузере, работа без сети. Сборка подписанных APK и EXE с контрольными суммами SHA-256 при выпуске.
- Документы: порядок выпуска (`docs/release.md`), правила для участников (`CONTRIBUTING.md`), решения (`docs/adr/`), правила для моделей (`AGENTS.md`), правила текстов (`docs/style.md`).

### Изменено
- Тексты интерфейса: без длинных тире, разделителя «·», первого лица и рекламных оборотов.
- README переписан для инспекторов и службы ИТ; описание для разработчиков перенесено в `CONTRIBUTING.md`.

## [1.0.1] - 23.11.2026

### Исправлено
- План по площади этажа: при снятой галочке площади остальных помещений пересчитываются (раньше оставались заниженными, вместе с ними занижалось число огнетушителей).
- Окно плана не закрывается нажатием мимо; «Назад» и Esc идут по шагам, во время распознавания окно не закрывается.
- Распознавание: план, обрезанный вплотную к стенам, не принимается за рамку листа; стена не уходит в соседнее помещение при поглощении мебели; сглаживание при уменьшении фото.
- Сохранение данных сразу при сворачивании и закрытии; сообщение при переполнении памяти; копия повреждённых данных вместо затирания; удаление картинок удалённых планов.
- Без адреса сайта кнопка «Ссылка на расчёт» не показывается; мера в перечне нарушений выводится отдельной строкой.
- `sw.js` не отдаёт файлы из папки входящих как страницы приложения.

### Безопасность
- Windows: PDF сохраняется через окно «Сохранить как» с результатом и кнопкой «Открыть»; инструменты разработчика в выпуске отключены; запросы в сеть отклоняются; переносная версия хранит данные рядом с собой.
- Android: отключены резервная копия Google и перенос данных системой и незашифрованный трафик; FileProvider открыт только для своей временной папки.

## [1.0.0] - 20.11.2026

### Добавлено
- Расчёт первичных средств пожаротушения по Приложению 3 к Правилам пожарной безопасности РК (приказ МЧС РК от 21.02.2022 № 55) и СТ РК 1487-2006: количество по площади, категории и классу пожара, расстояние до огнетушителя, передвижные огнетушители, 50 % при автоматическом пожаротушении.
- Ввод помещений по этажам, несколько объектов, быстрый ввод.
- План этажа по фото: масштаб по отрезку или по площади этажа, помещения и площади находятся на устройстве.
- Схема этажа «как есть» и «по нормам», перечень нарушений со ссылками на пункты норм.
- PDF-отчёт в виде служебного документа; QR-код со ссылкой на расчёт.
- Справочник норм с дословными текстами пунктов (`js/library.js`).
- Знаки на схеме по ГОСТ 12.4.026-2015.
- Работа без сети: приложение устанавливается как PWA и сохраняет все файлы на устройстве.
- Приложения: APK для Android 7 и новее (Capacitor), установщик и переносной EXE для Windows 10 и 11 (Electron).
