# Расчёт огнетушителей

Инструмент обхода для инспектора: по плану этажа или по введённым помещениям считает, сколько и каких огнетушителей (ОП, ОУ) нужно, сверяет с тем, что стоит на объекте, и выдаёт заключение с перечнем нарушений и схемой этажа в PDF. Работает на телефоне без сети.

Нормы: Приложение 3 к Правилам пожарной безопасности РК (приказ МЧС РК от 21.02.2022 № 55) и СТ РК 1487-2006.

## Идея

Задание звучит как «калькулятор: параметры здания → количество огнетушителей». Но инспектор приходит на объект не за числом. Он уходит с документом: что не так, на каком основании и как должно быть. Поэтому программа устроена вокруг обхода:

- инспектор фотографирует план эвакуации (он висит на каждом этаже) или загружает план из техпаспорта — помещения и их площади находятся сами, прямо на телефоне;
- схема этажа строится по этому плану (или по введённым вручную помещениям);
- инспектор нажимает на схему там, где огнетушитель стоит на самом деле;
- программа сразу показывает нарушения: не хватает, порошковый в серверной, дальше 20 м;
- вторая схема — «по нормам» — показывает, как должно быть;
- обе схемы и перечень нарушений попадают в PDF, а QR-код в нём открывает этот же расчёт на любом телефоне.

## Приложения для телефона и компьютера

Одна и та же программа собирается в три вида. Все работают без интернета: файлы приложения лежат внутри, объекты и картинки планов хранятся на устройстве.

Нажмите «Подробнее» → «Выполнить в любом случае». Чтобы предупреждения не было, нужен сертификат подписи кода (покупается у удостоверяющего центра).

Что умеют приложения сверх сайта:
- на Android PDF и ссылка отправляются через системное меню «Поделиться» (в мессенджер, на почту, в «Файлы»); кнопка «Назад» закрывает окна, а не приложение; кнопка «Сфотографировать план» открывает камеру;
- в Windows PDF сохраняется через окно «Сохранить как», окно приложения запоминает данные между запусками.

Данные хранятся отдельно в каждом приложении и в каждом браузере. Расчёт переносится между ними ссылкой (кнопка «Ссылка на этот расчёт») — без картинки плана.

### Сборка приложений

```
npm run app:android    # APK для Android
npm run app:windows    # установщик и переносной EXE для Windows
npm run app            # всё сразу
```

Нужно: Node 22; для Android — JDK 21 и Android SDK (платформа 36). Пути берутся из `JAVA_HOME` и `ANDROID_HOME`, а если их нет — из папки сборки `%LOCALAPPDATA%\firecalc-build` (`jdk`, `android-sdk`). Сборка идёт в копии проекта в этой же папке, не в OneDrive. Код приложений — в `native/`: `native/android` (Capacitor 8), `native/desktop` (Electron).

APK подписывается ключом выпуска: он создаётся при первой сборке в `%LOCALAPPDATA%\firecalc-build\keys`. **Сохраните эту папку.** Обновление ставится поверх старой версии только с тем же ключом; без него старое приложение придётся удалить вместе с сохранёнными объектами. В git ключ не попадает.

Ссылка на расчёт и QR-код в PDF ведут на опубликованный сайт. В приложениях адрес сайта берётся из `js/config.js` (`publicUrl`) или из параметра сборки `--public-url https://адрес/`; пока адреса нет, кнопка ссылки в приложениях сообщает об этом, а QR-кода в PDF нет. Номер версии — `version` в `package.json`.

## Сайт и работа без сети (PWA)

Сервер и установка не нужны: откройте `index.html` в браузере. Данные хранятся только в этом браузере.

Чтобы работать без сети и открывать расчёт с телефона, сайт нужно открыть по адресу (хостинг или локальный сервер):

```
python -m http.server 8765
```

Открытый по адресу сайт — устанавливаемое приложение (PWA):
- при первом открытии приложение целиком сохраняется на устройстве и дальше открывается сразу, без ожидания сети, включая PDF и распознавание плана;
- новая версия скачивается в фоне, приложение показывает «Вышла новая версия — Обновить» и переключается по нажатию, а не посреди работы;
- «Установить на это устройство» в меню «Объекты» (Chrome, Edge, Android); на iPhone — через «Поделиться» в Safari;
- ярлыки на значке: «Новый расчёт», «План этажа по фото», «Нормы»;
- на Android фото плана можно отправить в приложение из галереи через «Поделиться → Огнетушители», на компьютере — открыть картинку плана через «Открыть с помощью»;
- браузеру отправляется просьба не удалять сохранённые объекты при нехватке места.

После любого изменения файлов запустите `npm run build`: он ставит номер сборки в `sw.js`, `index.html` и `js/config.js` по содержимому файлов. Без нового номера установленные приложения не узнают об обновлении (тест `tests/pwa.test.js` это проверяет). Новый файл приложения добавьте в список `ASSETS` в `sw.js`.

Публикация: подойдёт любой хостинг статических файлов по https (Vercel, Netlify, свой сервер). На сайт идут файлы из корня проекта, кроме перечисленных в `.vercelignore`. Файл `sw.js` должен отдаваться без долгого кэширования (`vercel.json`).

Ссылки для показа:

- `index.html?demo=business` — пример «бизнес-центр»: на схеме первого этажа отмечено три порошковых огнетушителя (один в серверной), эвакуационный выход и пожарный кран;
- `index.html?demo=factory&open=all` — пример «производственная база» с раскрытыми расчётами;
- `index.html?demo=business&step=3` — на телефоне сразу вкладка «Результат»;
- `index.html?selfcheck=1&demo=business` — проверка, что PDF формируется в этом браузере.

## Как пользоваться

Слева вводятся помещения, справа сразу виден результат. На телефоне и планшете это две вкладки.

1. **По плану этажа.** Кнопка «Загрузить план» над этажами (видна всегда, в том числе после ввода имени объекта) или «Загрузить план этажа» у самого этажа.
   - Сфотографируйте план эвакуации или выберите картинку плана из техпаспорта. Снимайте прямо, чтобы план был целиком в кадре.
   - Масштаб: нажмите на два конца стены или линейки известной длины и укажите её — или введите общую площадь этажа.
   - «Найти помещения»: контуры и площади появляются за доли секунды. Распознавание идёт на самом устройстве, в фоновом потоке, без сервера и без сети.
   - Проверьте назначения: коридор узнаётся сам, серверной, щитовой, складу укажите своё (или впишите имя — назначение подставится). Лишнее снимите галочкой.
   - «Применить к этажу»: помещения попадают в расчёт, схема строится по настоящему плану. Отменить можно из уведомления.
   - Несколько этажей: «Применить и добавить этаж» сразу открывает план следующего этажа; та же «Добавить этаж по плану» есть над этажами и под их списком (пустой последний этаж берётся, новый не добавляется). У каждого этажа свой план и свой масштаб; «Дублировать» копирует этаж вместе с планом (типовые этажи).
   - «Заменить план этажа» открывает прежний план: можно пересчитать с другим масштабом или выбрать «Другое фото».
   - «Пример: план школы» — готовый план эвакуации с линейкой для показа.
2. **Помещения.** Выберите назначение здания и вводите помещения по этажам: назначение и площадь.
   - Кнопки под таблицей добавляют частые помещения одним нажатием.
   - Enter в поле площади добавляет следующую строку.
   - Одинаковые помещения вводятся одной строкой с количеством.
   - Категория и классы пожара подставляются по назначению; подпись в строке раскрывает их для правки.
   - Имя подсказывает назначение: помещение, названное «Серверная», «Щитовая», «Архив», само получает это назначение (уведомление с отменой). Назначение, выбранное из списка, по имени не меняется.
   - Нет рулетки — «Измерить шагами»: шаги переводятся в метры, площадь считается сама.
   - Этаж можно продублировать, удаление можно отменить.
3. **Схема этажа.** Кнопка под помещениями этажа.
   - «Как есть»: выберите, что отметить — огнетушитель (ОП, ОУ), пожарный кран, кнопку пожарной сигнализации, телефон, пожарный щит или эвакуационный выход — и нажмите на помещение там, где предмет стоит. Повторное нажатие на значок убирает его. Круг показывает предельное расстояние от огнетушителя, красным закрашено то, что дальше нормы. Краны, кнопки, телефоны, щиты и выходы показываются на схеме и в PDF, но в число огнетушителей и в проверку расстояния не входят.
   - Значки — знаки безопасности по ГОСТ 12.4.026-2015 (см. «Значки на схеме» ниже); под схемой — условные обозначения.
   - «По нормам»: расстановка, которую даёт расчёт. Огнетушители ставятся в первую очередь в коридоры и расходятся по ним равномерно; в отдельном помещении — у стены со стороны коридора (у выхода, п. 12); второй огнетушитель в помещении без коридора — у середины противоположной стены, а не в углу. С фактом не смешивается; отмеченные выходы, краны и прочие предметы видны и здесь.
   - «Двигать»: помещения перетаскиваются так, как они стоят на этаже (помещения с загруженного плана стоят на своих местах). Огнетушители остаются в своих помещениях.
4. **Результат.** Итог по типам, сверка с фактом, перечень нарушений со ссылками на пункты норм, расчёт по каждому помещению.
   - Если на схеме ничего не отмечено, количество установленных ОП и ОУ можно вписать числом.
5. **PDF.** Кнопка «Скачать PDF» спрашивает данные для отчёта (адрес, собственник, кто выполнил) и формирует документ. Он оформлен как служебный расчёт, а не как экран приложения: шрифт с засечками (Tinos, метрика Times New Roman), чёрный текст, пронумерованные разделы, таблицы с сеткой, без цветных плашек и карточек. Цветные только знаки на схемах — так требует ГОСТ 12.4.026-2015.
   - Первая страница: сведения об объекте, требуемое количество по типам и этажам, сверка с фактическим наличием, выявленные нарушения с мерами и пунктами норм, вывод «соответствует / не соответствует», подписи и небольшой QR-код.
   - Приложения, каждое с новой страницы: схемы «фактическое размещение» и «размещение по расчёту» со знаками и условными обозначениями, расчёт по помещениям с формулами, требования к размещению, принятые допущения и нормативные документы.
6. **Ссылка на расчёт.** Весь расчёт лежит в самой ссылке, сервера нет. Та же ссылка печатается QR-кодом в PDF (если сайт открыт по адресу и ссылка не длиннее 1000 знаков — это примерно 3 этажа по 15 помещений): камера телефона открывает расчёт для повторной проверки. Код ведёт на тот адрес, с которого сформирован PDF, поэтому для показа отчёт нужно формировать на опубликованном сайте.

Объектов может быть несколько: «Новый расчёт» начинает следующий, «Объекты» открывает список сохранённых.

7. **Нормы.** Кнопка «Нормы» в шапке (на телефоне — в меню «Объекты») открывает справочник: дословные тексты пунктов, на которые опирается программа, с поиском. Работает без сети.

## Значки на схеме

Правила пожарной безопасности РК требуют обозначать места размещения первичных средств пожаротушения знаками пожарной безопасности, а их цветографическое изображение брать из документов по стандартизации (п. 18 и п. 166); на плане эвакуации показывают выходы, кнопки ручных пожарных извещателей, телефоны, пожарные краны и огнетушители (приложение 2). Поэтому значки на схеме — знаки по ГОСТ 12.4.026-2015 (межгосударственный стандарт, Казахстан голосовал за его принятие):

| На схеме | Знак | Цвет |
|---|---|---|
| Огнетушитель порошковый, буква П | F04 «Огнетушитель» | красный |
| Огнетушитель углекислотный, буква У | F04 «Огнетушитель» | красный |
| Пожарный кран | F02 «Пожарный кран» | красный |
| Кнопка пожарной сигнализации | F10 «Кнопка включения установок (систем) пожарной автоматики» | красный |
| Телефон | F05 «Телефон для использования при пожаре» | красный |
| Пожарный щит | F06 «Место размещения нескольких средств противопожарной защиты» | красный |
| Эвакуационный выход | E01 «Выход здесь» | зелёный |

Знаки пожарной безопасности — красный квадрат с белым символом, эвакуационные — зелёный (ГОСТ 12.4.026-2015, табл. 1 и 2; образцы цвета RAL 3020 и RAL 6024, прил. В). Корпус огнетушителя любого типа красный (ГОСТ 30612-99, п. 4.4.28; ГОСТ 12.4.026-2015, п. 5.1.2), поэтому порошковый и углекислотный различаются не цветом знака, а буквой в кружке у знака (ГОСТ 28130-89, п. 1.2 и 1.5: буквенные обозначения объясняются в условных обозначениях). Символы нарисованы заново по образцам приложений К и Л стандарта и упрощены, чтобы читаться при размере 16–24 точки (`js/signs.js`).

Не считаются: предприятия нефтепродуктообеспечения (Прил. 10), строящиеся здания (Прил. 11), транспорт, пожарные щиты (табл. 3 и 4).

Правила не определяют некоторые детали (как округлять, что считать «небольшим» помещением и т. п.). Принятые решения перечислены в интерфейсе в разделе «Как считаем» и в каждом PDF. Их нужно согласовать с ДЧС перед применением.

Текста СТ РК 1487-2006 в открытом доступе нет. Два правила взяты в той формулировке, в какой они есть в стандартах на эксплуатацию огнетушителей с тем же названием (НПБ 166-97 и СП 9.13130.2009); их нужно сверить по тексту СТ РК:

- не менее двух переносных огнетушителей на каждом этаже «общественных и промышленных зданий» (НПБ 166-97, п. 5.23; СП 9.13130.2009, п. 4.1.23). Приложение 3 (п. 5) требует этого только в общественных зданиях, поэтому для производственных и складских это параметр расчёта; этажи, где нет помещений по табл. 1 (только объекты табл. 5 или категория Д менее 100 м²), не дополняются;
- порошковые огнетушители не применяются для оборудования, которое может выйти из строя при попадании порошка (НПБ 166-97, п. 5.6; СП 9.13130.2009, п. 4.1.6). В отчёте основание указано как «Прил. 3, п. 9; СТ РК 1487-2006» без номера пункта стандарта.

Расстояние на схеме считается по прямой, без стен и дверей; фактический путь может быть длиннее.

Распознавание плана:
- стены — тёмные линии; цветное (стрелки эвакуации, знаки) и мелкие надписи пропускаются, неровный свет на снимке учитывается;
- помещения разделяются по «глубине» — расстоянию до стен: помещение отделяется проёмом, если само заметно шире проёма (хотя бы на 0,2 м глубже его середины). Поэтому ширина двери в точках картинки не важна, и большое здание, снятое одной картинкой (около 10 точек на метр, дверь — 10 точек), распознаётся целиком. Проём не уже трёх четвертей ширины помещения (арка, сужение) — одно помещение;
- мебель — не помещение: отдельно стоящие предметы (стол, стулья, колонна, значок) стенами не считаются; замкнутый контур у стены или в углу (кровать, шкаф, кухонная тумба, ванна), за тонкой линией которого почти везде одно и то же помещение, присоединяется к нему вместе с площадью; на крупном плане (от 25 точек на метр) тонкие линии — мебель, створки и дуги дверей, размеры — стенами не считаются. Кусок стены между дверями, отделённый от стен просветом в точку, остаётся стеной;
- площадь — по внутренним граням стен; на снимке размытые стены толще, площадь выходит чуть меньше (на тестовом снимке — до 1 %);
- масштаб задаётся отрезком известной длины или общей площадью этажа. Длину можно вписать сразу, а концы отрезка отметить потом; длину больше 300 м программа предлагает перевести из миллиметров или сантиметров. По общей площади первый масштаб оценивается по габариту здания на картинке, затем уточняется по найденным помещениям, так что сумма площадей совпадает с введённой. Если на метр плана приходится меньше 3 точек (обычно площадь или длина введены не в тех единицах), программа предупреждает;
- площади помещений округляются до 0,1 м² так, что их сумма равна общей площади: итог в списке, в уведомлении и в расчёте этажа один и тот же;
- перспективу снимка программа не исправляет — снимайте план прямо;
- картинка плана хранится только на этом устройстве; в ссылку и QR-код она не попадает, помещения с площадями — попадают.

## Проверка

```
node --test                    # тесты: расчёт (в том числе эталонные примеры и 3000 случайных объектов), распознавание плана (в том числе большое здание и квартира с мебелью), схема и знаки, ссылка, отчёт, справочник норм, PWA (манифест, работа без сети, номер сборки)
npm run check:ui               # проверка интерфейса в Edge или Chrome без окна (tests/ui-smoke.html)
npm run build                  # номер сборки по содержимому файлов (после любых изменений)
node tools/make-screens.js     # снимки экрана для окна установки (icons/screens/)
node tools/sample-pdf.js       # PDF для обоих примеров в папку out/
node tools/make-pdf-fonts.js   # шрифт отчёта vendor/vfs_report.js из vendor/fonts/Tinos-*.ttf
node tools/make-example-plan.js  # пример плана: examples/plan-school.svg и .json (PNG — снимок SVG 1:1)
```

Проверка интерфейса: `npm run check:ui` или вручную — запустите локальный сервер и откройте `http://localhost:8765/tests/ui-smoke.html`. Страница сама нажимает кнопки и сверяет результат (включая планы нескольких этажей по картинке, ввод длины отрезка, схему, назначение по имени и ширину телефона).

|---|---|
| `js/norms.js` | Таблицы 1, 2, 5 и тексты пунктов. Таблицы 1 и 2 сверены с официальным текстом по каждой ячейке |

| `js/platform.js`, `js/config.js` | Где запущено приложение (сайт, Android, Windows): сохранение PDF, ссылка, установка, обновление; адрес сайта и номер версии |

| `js/share.js` | Расчёт в ссылке: упаковка, сжатие, разбор |
