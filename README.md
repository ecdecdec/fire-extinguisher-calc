# Расчёт огнетушителей

Инструмент обхода для инспектора: по помещениям считает, сколько и каких огнетушителей (ОП, ОУ) нужно, сверяет с тем, что стоит на объекте, и выдаёт перечень нарушений со схемой этажа в PDF.

Нормы: Приложение 3 к Правилам пожарной безопасности РК (приказ МЧС РК от 21.02.2022 № 55) и СТ РК 1487-2006.

## Идея

Задание звучит как «калькулятор: параметры здания → количество огнетушителей». Но инспектор приходит на объект не за числом. Он уходит с документом: что не так, на каком основании и как должно быть. Поэтому программа устроена вокруг обхода:

- схема этажа строится сама по введённым помещениям;
- инспектор нажимает на схему там, где огнетушитель стоит на самом деле;
- программа сразу показывает нарушения: не хватает, порошковый в серверной, дальше 20 м;
- вторая схема — «по нормам» — показывает, как должно быть;
- обе схемы и перечень нарушений попадают в PDF, а QR-код в нём открывает этот же расчёт на любом телефоне.

## Запуск

Сервер и установка не нужны: откройте `index.html` в браузере. Данные хранятся только в этом браузере.

Чтобы работать без сети и открывать расчёт с телефона, сайт нужно открыть по адресу (хостинг или локальный сервер):

```
python -m http.server 8765
```

После первого открытия по адресу приложение сохраняется в браузере и дальше запускается без интернета, включая PDF. На телефоне его можно добавить на главный экран.

Ссылки для показа:

- `index.html?demo=business` — пример «бизнес-центр»: на схеме первого этажа отмечено три порошковых огнетушителя, один из них в серверной;
- `index.html?demo=factory&open=all` — пример «производственная база» с раскрытыми расчётами;
- `index.html?demo=business&step=3` — на телефоне сразу вкладка «Результат»;
- `index.html?selfcheck=1&demo=business` — проверка, что PDF формируется в этом браузере.

## Как пользоваться

Слева вводятся помещения, справа сразу виден результат. На телефоне и планшете это две вкладки.

1. **Помещения.** Выберите назначение здания и вводите помещения по этажам: назначение и площадь.
   - Кнопки под таблицей добавляют частые помещения одним нажатием.
   - Enter в поле площади добавляет следующую строку.
   - Одинаковые помещения вводятся одной строкой с количеством.
   - Категория и классы пожара подставляются по назначению; подпись в строке раскрывает их для правки.
   - Имя подсказывает назначение: помещение, названное «Серверная», «Щитовая», «Архив», само получает это назначение (уведомление с отменой). Назначение, выбранное из списка, по имени не меняется.
   - Нет рулетки — «Измерить шагами»: шаги переводятся в метры, площадь считается сама.
   - Этаж можно продублировать, удаление можно отменить.
2. **Схема этажа.** Кнопка под помещениями этажа.
   - «Как есть»: нажатие на помещение отмечает огнетушитель (ОП или ОУ), повторное нажатие на него — убирает. Круг показывает предельное расстояние, красным закрашено то, что дальше нормы.
   - «По нормам»: расстановка, которую даёт расчёт. С фактом не смешивается.
   - «Двигать»: помещения перетаскиваются так, как они стоят на этаже. Огнетушители остаются в своих помещениях.
3. **Результат.** Итог по типам, сверка с фактом, перечень нарушений со ссылками на пункты норм, расчёт по каждому помещению.
   - Если на схеме ничего не отмечено, количество установленных ОП и ОУ можно вписать числом.
4. **PDF.** Кнопка «Скачать PDF» спрашивает данные для отчёта (адрес, собственник, кто выполнил) и формирует документ: итог, сверка, перечень нарушений, расчёт, схемы «как есть» и «по нормам», подписи.
5. **Ссылка на расчёт.** Весь расчёт лежит в самой ссылке, сервера нет. Та же ссылка печатается QR-кодом в PDF (если сайт открыт по адресу и ссылка не длиннее 1000 знаков — это примерно 3 этажа по 15 помещений): камера телефона открывает расчёт для повторной проверки. Код ведёт на тот адрес, с которого сформирован PDF, поэтому для показа отчёт нужно формировать на опубликованном сайте.

Объектов может быть несколько: «Новый расчёт» начинает следующий, «Объекты» открывает список сохранённых.

## Что считается и проверяется

| Правило | Пункт Приложения 3 |
|---|---|
| Количество по площади, категории и классу пожара | п. 3, табл. 1 |
| Расстояние до огнетушителя 20 / 30 / 40 / 70 м — числом мест и на схеме | п. 4 |
| Не менее двух огнетушителей на этаже: в общественном здании — по п. 5, в производственном и складском — параметр расчёта (включён по умолчанию, см. ниже) | п. 5 |
| Помещения категории Д менее 100 м² не оснащаются | п. 6 |
| Небольшие помещения одной категории — по суммарной площади | п. 7 |
| Углекислотные огнетушители для электроники, архивов, музеев; порошковый в таких помещениях — нарушение | п. 9 |
| 50 % при автоматическом пожаротушении | п. 10 |
| Передвижные огнетушители для больших помещений | п. 2, табл. 2 |
| СТО, стоянки, гаражи, АЗС, встроенные магазины и офисы | табл. 5 |

Не считаются: предприятия нефтепродуктообеспечения (Прил. 10), строящиеся здания (Прил. 11), транспорт, пожарные щиты (табл. 3 и 4).

Правила не определяют некоторые детали (как округлять, что считать «небольшим» помещением и т. п.). Принятые решения перечислены в интерфейсе в разделе «Как считаем» и в каждом PDF. Их нужно согласовать с ДЧС перед применением.

Текста СТ РК 1487-2006 в открытом доступе нет. Два правила взяты в той формулировке, в какой они есть в стандартах на эксплуатацию огнетушителей с тем же названием (НПБ 166-97 и СП 9.13130.2009); их нужно сверить по тексту СТ РК:

- не менее двух переносных огнетушителей на каждом этаже «общественных и промышленных зданий» (НПБ 166-97, п. 5.23; СП 9.13130.2009, п. 4.1.23). Приложение 3 (п. 5) требует этого только в общественных зданиях, поэтому для производственных и складских это параметр расчёта; этажи, где нет помещений по табл. 1 (только объекты табл. 5 или категория Д менее 100 м²), не дополняются;
- порошковые огнетушители не применяются для оборудования, которое может выйти из строя при попадании порошка (НПБ 166-97, п. 5.6; СП 9.13130.2009, п. 4.1.6). В отчёте основание указано как «Прил. 3, п. 9; СТ РК 1487-2006» без номера пункта стандарта.

Расстояние на схеме считается по прямой, без стен и дверей; фактический путь может быть длиннее.

## Проверка

```
node --test                  # 53 теста расчёта, схемы, ссылки и отчёта
node tools/sample-pdf.js     # PDF для обоих примеров в папку out/
```

Проверка интерфейса: запустите локальный сервер и откройте `http://localhost:8765/tests/ui-smoke.html`. Страница сама нажимает кнопки и сверяет результат (128 проверок, включая схему этажа, назначение по имени и ширину телефона).

## Файлы

| Файл | Назначение |
|---|---|
| `js/norms.js` | Таблицы 1, 2, 5 и тексты пунктов. Таблицы 1 и 2 сверены с официальным текстом по каждой ячейке |
| `js/engine.js` | Расчёт. Не зависит от браузера |
| `js/plan.js` | Схема этажа: расположение помещений, расстояние до огнетушителя, расстановка по нормам, перечень нарушений. Не зависит от браузера |
| `js/share.js` | Расчёт в ссылке: упаковка, сжатие, разбор |
| `js/presets.js` | Назначения помещений, кнопки быстрого добавления и примеры |
| `js/report.js` | Описание PDF-отчёта |
| `js/app.js`, `css/app.css`, `index.html` | Интерфейс |
| `sw.js`, `manifest.webmanifest`, `icons/` | Работа без сети и установка на телефон. Значки рисует `tools/make-icons.js` |
| `vendor/` | Vue 3.4.38, pdfmake 0.2.10 и шрифты IBM Plex (лицензия OFL) — лежат локально, интернет не нужен |
| `docs/analogs.md` | Аналоги в других странах |

При изменении файлов увеличьте номер версии `?v=` в `index.html`, иначе браузеры могут взять старые файлы из кэша. При изменении списка файлов увеличьте номер в `CACHE` в `sw.js`.
