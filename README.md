# Расчёт огнетушителей

Веб-сервис для инспектора: по параметрам здания считает типы и количество огнетушителей (ОП, ОУ) и формирует PDF-отчёт.

Нормы: Приложение 3 к Правилам пожарной безопасности РК (приказ МЧС РК от 21.02.2022 № 55) и СТ РК 1487-2006.

## Запуск

Сервер и установка не нужны: откройте `index.html` в браузере. Данные хранятся только в этом браузере.

Чтобы открыть с телефона в той же сети или выложить на хостинг, подойдёт любой статический сервер, например:

```
python -m http.server 8765
```

Ссылки для показа:

- `index.html?demo=business` — пример «бизнес-центр»;
- `index.html?demo=factory&open=all` — пример «производственная база» с раскрытыми расчётами;
- `index.html?demo=business&step=3` — на телефоне сразу вкладка «Результат»;
- `index.html?selfcheck=1&demo=business` — проверка, что PDF формируется в этом браузере.

## Как пользоваться

Слева вводятся помещения, справа сразу виден результат. На телефоне и планшете это две вкладки.

1. **Помещения.** Выберите назначение здания и вводите помещения по этажам: назначение и площадь.
   - Кнопки под таблицей добавляют частые помещения одним нажатием.
   - Enter в поле площади добавляет следующую строку.
   - Одинаковые помещения вводятся одной строкой с количеством.
   - Категория и классы пожара подставляются по назначению; подпись в строке раскрывает их для правки.
   - Этаж можно продублировать, удаление можно отменить.
2. **Результат.** Итог по типам, расчёт по каждому помещению со строкой нормативной таблицы и ссылками на пункты норм.
3. **Сверка с фактом.** В таблице результата впишите, сколько ОП и ОУ установлено на этаже, и появится вывод «соответствует» или «не соответствует».
4. **PDF.** Кнопка «Скачать PDF» спрашивает данные для отчёта (адрес, собственник, кто выполнил) и формирует документ.

Объектов может быть несколько: «Новый расчёт» начинает следующий, «Объекты» открывает список сохранённых.

## Что считается

| Правило | Пункт Приложения 3 |
|---|---|
| Количество по площади, категории и классу пожара | п. 3, табл. 1 |
| Расстояние до огнетушителя 20 / 30 / 40 / 70 м | п. 4 |
| Не менее двух огнетушителей на этаже общественного здания | п. 5 |
| Помещения категории Д менее 100 м² не оснащаются | п. 6 |
| Небольшие помещения одной категории — по суммарной площади | п. 7 |
| Углекислотные огнетушители для электроники, архивов, музеев | п. 9 |
| 50 % при автоматическом пожаротушении | п. 10 |
| Передвижные огнетушители для больших помещений | п. 2, табл. 2 |
| СТО, стоянки, гаражи, АЗС, встроенные магазины и офисы | табл. 5 |

Не считаются: предприятия нефтепродуктообеспечения (Прил. 10), строящиеся здания (Прил. 11), транспорт, пожарные щиты (табл. 3 и 4).

Правила не определяют некоторые детали (как округлять, что считать «небольшим» помещением и т. п.). Принятые решения перечислены в интерфейсе в разделе «Как считаем» и в каждом PDF. Их нужно согласовать с ДЧС перед применением.

## Проверка

```
node --test                  # 35 тестов расчёта и отчёта
node tools/sample-pdf.js     # PDF для обоих примеров в папку out/
```

Проверка интерфейса: запустите локальный сервер и откройте `http://localhost:8765/tests/ui-smoke.html`. Страница сама нажимает кнопки и сверяет результат (83 проверки, включая ширину телефона).

## Файлы

| Файл | Назначение |
|---|---|
| `js/norms.js` | Таблицы 1, 2, 5 и тексты пунктов. Таблицы 1 и 2 сверены с официальным текстом по каждой ячейке |
| `js/engine.js` | Расчёт. Не зависит от браузера |
| `js/presets.js` | Назначения помещений, кнопки быстрого добавления и примеры |
| `js/report.js` | Описание PDF-отчёта |
| `js/app.js`, `css/app.css`, `index.html` | Интерфейс |
| `vendor/` | Vue 3.4.38, pdfmake 0.2.10 и шрифты IBM Plex (лицензия OFL) — лежат локально, интернет не нужен |
| `docs/analogs.md` | Аналоги в других странах |

При изменении файлов увеличьте номер версии `?v=` в `index.html`, иначе браузеры могут взять старые файлы из кэша.
