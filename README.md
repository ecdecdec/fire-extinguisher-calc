# Огнетушители: расчёт и проверка первичных средств пожаротушения

Прикладная программа для инспекторов ДЧС Республики Казахстан и инженеров по пожарной безопасности. Выполняет расчёт требуемого количества переносных и передвижных огнетушителей (ОП, ОУ) по плану этажа или по перечню помещений, сверяет потребность с фактическим наличием на объекте, строит схему этажа со знаками пожарной безопасности и формирует служебный отчёт в формате PDF.

Нормативная база:
- Приложение 3 к Правилам пожарной безопасности Республики Казахстан (приказ МЧС РК от 21.02.2022 № 55);
- Технический регламент «Общие требования к пожарной безопасности» (приказ МЧС РК от 17.08.2021 № 405, приложение 16);
- СТ РК 1487-2006 «Техника пожарная. Огнетушители. Требования к эксплуатации»;
- ГОСТ 12.4.026-2015 (ISO 7010) «Цвета сигнальные, знаки безопасности и разметка сигнальная».

## Назначение и возможности

- **Распознавание плана этажа на устройстве**: по фотографии плана эвакуации или изображению из технического паспорта программа находит контуры помещений и вычисляет их площади по заданному отрезку известной длины или общей площади этажа. Обработка выполняется в фоновом потоке на самом устройстве, без отправки изображений на сервер.
- **Поэтажный ввод помещений**: выбор назначения объекта (общественное, производственное, складское), автоматическая подстановка категории по взрывопожарной и пожарной опасности (А, Б, В1–В4, Г, Д) и классов пожара по назначению помещения, учёт автоматических установок пожаротушения (снижение на 50 % по п. 10) и помещений с электронным оборудованием (углекислотные огнетушители по п. 9).
- **Схема этажа**: режим «Как есть» для отметки фактического расположения огнетушителей, пожарных кранов, кнопок сигнализации, телефонов, пожарных щитов и эвакуационных выходов с проверкой предельного расстояния до возможного очага пожара (20, 30, 40, 70 м по п. 4); режим «По нормам» с расстановкой по результатам расчёта.
- **Перечень нарушений и PDF-отчёт**: сводка требуемого и фактического количества по типам и этажам, список выявленных нарушений с указанием пункта норм и меры устранения, формирование строгого служебного документа PDF со схемами этажей и построчным расчётом.
- **Справочник норм**: встроенные дословные тексты пунктов Правил пожарной безопасности, Технического регламента и стандартов с поиском без подключения к сети.

## Установка

Приложение поставляется в трёх видах, собранных из одного исходного кода. Все варианты работают без подключения к интернету.

| Платформа | Файл поставки | Способ установки |
|---|---|---|
| Android 7 и новее | `Ognetushiteli-<версия>.apk` | Скопируйте APK на устройство по кабелю USB, через внутренний портал ведомства или систему MDM и откройте файл в проводнике. При первой установке разрешите установку из выбранного источника в настройках Android. |
| Windows 10 и 11 (64-бит), установщик | `Ognetushiteli-Setup-<версия>.exe` | Запустите установщик. Права администратора не требуются (программа ставится в профиль пользователя), создаются ярлыки на рабочем столе и в меню «Пуск». |
| Windows 10 и 11 (64-бит), переносная версия | `Ognetushiteli-<версия>-portable.exe` | Установка не требуется. Поместите файл в рабочую папку на компьютере или на разрешённом съёмном носителе и запустите. |
| Внутренний сервер (PWA: Windows, Android, iPhone, iPad) | Веб-сайт по протоколу HTTPS | Откройте адрес внутреннего сервера в браузере (Chrome, Edge, Safari) и выберите «Установить на это устройство» (в Safari на iPhone: «Поделиться -> На экран Домой»). |

Примечание для службы ИТ по запуску в Windows: если исполняемый файл `.exe` не подписан сертификатом издателя кода, фильтр Windows SmartScreen при первом запуске покажет окно «Система Windows защитила ваш компьютер». Сверьте контрольную сумму файла с `SHA256SUMS.txt`, нажмите «Подробнее» и «Выполнить в любом случае». В централизованной инфраструктуре служба ИТ может подписать `.exe` ведомственным сертификатом подписи кода.

## Обновление

- **Android**: установите новый файл `Ognetushiteli-<версия>.apk` поверх существующего приложения. Если новый выпуск подписан тем же ключом подписи, сохранённые объекты остаются на устройстве. Не удаляйте старую версию перед обновлением.
- **Windows (установщик)**: запустите `Ognetushiteli-Setup-<версия>.exe` поверх установленной программы. Данные объектов в профиле пользователя сохраняются.
- **Windows (переносная версия)**: замените исполняемый файл `Ognetushiteli-<версия>-portable.exe` в папке, где расположена папка `Огнетушители-данные`.
- **Сайт во внутренней сети (PWA)**: при подключении устройства к внутреннему серверу новая сборка загружается в фоне. В приложении появляется уведомление «Вышла новая версия» с кнопкой «Обновить»; переключение происходит по нажатию кнопки, без прерывания текущей работы.

Подробный порядок выпуска, проверки контрольных сумм SHA-256 и развёртывания описан в [docs/release.md](docs/release.md).

## Где хранятся данные и как сделать резервную копию

Все введённые объекты, планы этажей и расчёты хранятся локально на том устройстве, где запущена программа:

- **Android (APK)**: внутреннее изолированное хранилище приложения (`/data/data/kz.firecalc.app/`). Другие приложения не имеют к нему доступа. Облачное резервное копирование Google отключено (`android:allowBackup="false"`).
- **Windows (установленная версия)**: папка профиля текущего пользователя `%APPDATA%\firecalc-apps` (хранилище Chromium/Electron).
- **Windows (переносная версия)**: папка `Огнетушители-данные`, которая автоматически создаётся в той же папке, где лежит файл `Ognetushiteli-<версия>-portable.exe`. На чужом компьютере в системном профиле Windows данные не остаются.
- **Сайт (PWA)**: локальное хранилище выбранного браузера, привязанное к адресу сайта. При запуске приложение запрашивает у браузера защиту хранилища от автоматической очистки (`navigator.storage.persist()`).

### Резервное копирование и перенос

- В переносной версии для Windows для резервной копии достаточно скопировать папку `Огнетушители-данные` на защищённый носитель или в сетевую папку пользователя.
- В установленной версии для Windows резервная копия создаётся копированием папки `%APPDATA%\firecalc-apps`.
- Готовые расчёты сохраняются в файлы PDF (кнопка сохранения PDF).
- При развёрнутом внутреннем веб-сервере расчёт (помещения, площади, отметки на схеме, без исходного фото плана) может передаваться ссылкой или QR-кодом на первой странице PDF.

## Разрешения и зачем они нужны

### Android

- Приложение не запрашивает доступ к контактам, геолокации, микрофону, телефонным вызовам или постоянному чтению всех файлов устройства.
- Снимок плана этажа передаётся в приложение через системное окно выбора файла или системное приложение камеры по явному действию пользователя.
- Для передачи сформированного PDF-отчёта в другие программы (печать, почта, файловый менеджер) используется системный механизм `FileProvider`, доступ которого ограничен только временной папкой выгрузки (`cache/share`).
- Разрешение `android.permission.INTERNET` присутствует в стандартном шаблоне оболочки Capacitor для работы локального моста WebView; само приложение не выполняет сетевых запросов, а незашифрованный трафик запрещён (`android:usesCleartextTraffic="false"`).

### Windows

- Приложение работает в изолированном окне Electron (`contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`).
- Внутри окна разрешены только запись в буфер обмена по действию пользователя (`clipboard-sanitized-write`) и постоянное локальное хранилище (`persistent-storage`). Запросы к камере, микрофону, геолокации и уведомлениям отклоняются.
- Сохранение PDF выполняется только через системное диалоговое окно «Сохранить как» по выбору пользователя.

## Работа без сети и безопасность

Приложение разработано с учётом Единых требований в области информационно-коммуникационных технологий и обеспечения информационной безопасности (постановление Правительства РК от 20.12.2016 № 832):

- **Полная автономность**: программе не требуется подключение к интернету ни при запуске, ни при распознавании планов этажей, ни при расчёте и формировании PDF. Все программные модули и шрифты включены в поставку (`vendor/`).
- **Блокировка внешних обращений**: в приложении для Windows все исходящие сетевые запросы по протоколам `http://`, `https://`, `ws://` и `wss://` принудительно блокируются на уровне сессии (`webRequest.onBeforeRequest`), а страница загружается только по внутреннему протоколу `app://firecalc/`.
- **Отсутствие телеметрии**: в коде нет счётчиков аналитики, внешних шрифтов, CDN и фоновых проверок обновлений во внешних сетях.
- **Проверка целостности**: каждый выпуск сопровождается файлом `SHA256SUMS.txt` с контрольными суммами SHA-256 всех установочных файлов (см. [docs/release.md](docs/release.md)).

Подробное описание мер защиты, разрешений, настроек сборки и перечень сторонних компонентов для службы информационной безопасности приведены в [docs/security.md](docs/security.md).

## Что считается и проверяется

| Требование | Основание (Приложение 3 к ППБ РК) |
|---|---|
| Количество огнетушителей по площади, категории помещения и классу пожара | п. 3, табл. 1 |
| Предельное расстояние от возможного очага пожара до места размещения (20, 30, 40, 70 м) | п. 4 |
| Не менее двух переносных огнетушителей на каждом этаже общественного здания (для производственных и складских зданий задаётся параметром расчёта по СТ РК 1487-2006) | п. 5 |
| Помещения категории Д площадью менее 100 м² не оснащаются | п. 6 |
| Несколько небольших помещений одной категории оснащаются по суммарной площади | п. 7 |
| Помещения с вычислительной техникой, АТС, архивами и музеями оснащаются углекислотными огнетушителями; применение порошковых фиксируется как нарушение | п. 9, СТ РК 1487-2006 |
| При наличии автоматических установок пожаротушения количество сокращается на 50 % | п. 10 |
| Передвижные огнетушители для помещений большой площади | п. 2, табл. 2 |
| СТО, стоянки, гаражи, АЗС, встроенные магазины и офисы | табл. 5 |

Ограничения текущей области расчёта:
- не рассчитываются предприятия нефтепродуктообеспечения (Приложение 10), строящиеся и реконструируемые объекты (Приложение 11), транспортные средства и комплектация пожарных щитов (таблицы 3 и 4 Приложения 3);
- расстояние на схеме этажа проверяется по прямой линии в пределах этажа; фактический путь обхода перегородок на объекте может быть длиннее;
- принятые допущения расчёта (правила округления, порог площади для группировки по п. 7, ссылки на положения СТ РК 1487-2006) явно выводятся в интерфейсе программы и в каждом формируемом PDF-отчёте.

## Знаки безопасности на схеме и в отчёте

В соответствии с п. 18, п. 166 и Приложением 2 к Правилам пожарной безопасности РК места размещения средств пожаротушения и элементы плана эвакуации обозначаются знаками по ГОСТ 12.4.026-2015 (символы согласованы с международным стандартом ISO 7010):

| Обозначение на схеме | Код по ГОСТ 12.4.026-2015 (ISO 7010) | Сигнальный цвет |
|---|---|---|
| Огнетушитель порошковый (буква П) | F04 (F001) «Огнетушитель» | Красный (RAL 3020) |
| Огнетушитель углекислотный (буква У) | F04 (F001) «Огнетушитель» | Красный (RAL 3020) |
| Пожарный кран | F02 (F002) «Пожарный кран» | Красный (RAL 3020) |
| Кнопка пожарной сигнализации | F10 (F005) «Кнопка включения установок пожарной автоматики» | Красный (RAL 3020) |
| Телефон при пожаре | F05 (F006) «Телефон для использования при пожаре» | Красный (RAL 3020) |
| Пожарный щит | F06 (F004) «Место размещения нескольких средств противопожарной защиты» | Красный (RAL 3020) |
| Эвакуационный выход | E01 (E001) «Выход здесь» | Зелёный (RAL 6024) |
